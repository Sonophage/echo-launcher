Using ECHO

How to install ECHO, what every screen does, and where every setting lives. In menu paths, ≡ is the Y button, which opens a thing's options; on touch, long-press instead. These docs describe ECHO 2.9.

01Getting started

Install

You need Android 10 (API 29) or newer, and the emulators you want to use, installed separately; ECHO launches them and does not emulate anything itself. A controller is recommended, and touch works throughout.

With Obtainium (updates arrive by themselves)

  1. Install Obtainium from its releases page, F-Droid or IzzyOnDroid.
  2. Tap Add App and paste https://github.com/Sonophage/echo-launcher
  3. Set Filter APKs by regular expression to ^ECHO-[0-9.]+\.apk$ so you always get the normal app. The other file, ECHO-<version>-debug.apk, installs as a second app beside it.
  4. Tap Add, then Install, and allow installs from Obtainium when Android asks.
  5. Press Home, pick ECHO and choose Always.

Every release is signed with the same key, so an update installs over the old one and keeps your library.

By hand, from the APK

  1. Download ECHO-<version>.apk from the latest release.
  2. Open it on the device, allow installs from that source, and tap Install.
  3. Press Home, pick ECHO and choose Always. Importing shortcuts from other launchers needs ECHO to be the default home app.

To update, install the newer APK over the old one. To go back to your old launcher, pick it in Android Settings ▸ Apps ▸ Default apps ▸ Home app; back up first if you might return.

First run

A fresh install opens the setup wizard. Every step is optional and sets the same thing as the matching Settings screen. Run it again any time from Settings ▸ Setup ▸ Setup Wizard.

  1. What ECHO is for: Gaming and Media, each on or off. Both off is a launcher only. What is off is left out of the next steps and hidden from the crossbar; Panel ▸ Libraries brings a column back.
  2. The ECHO folder: where ECHO keeps artwork and its look (more below).
  3. Permissions: each one turns something on; none is required.
  4. Your folders: the Games folder (one subfolder per console, the ES-DE names: gba, snes, psx…), then Music, Video, Photos and Books. Adding the Games folder scans it and creates a card for every console that has games.
  5. Emulators: RetroArch and the Vita3K data folder, when installed.
  6. Accounts: achievements, Discord and the artwork sources. Then Finish.

Permissions

ECHO asks only when a feature needs something. Settings ▸ Accounts ▸ Permissions shows what is granted and opens the screen to grant the rest.

Home and Last Played

The first column is Last Played: games, apps, music, video and books together, newest first. Whatever is focused fills the screen, with the wave behind it in the colour of its art, and beside it its play time, platform, year, genre, developer and your achievements. LT/RT filter it (All, Games, Music, Books, Video, Apps).

  • Press LEFT, or swipe right, for the Recent rail. X on a row takes it off Recent; it comes back the next time you open it, and your play history is kept.
  • ≡ ▸ Pin to Recent on a game or app puts it in the Pinned group at the top.
  • Look ▸ Crossbar ▸ Last Played Size sets how many it holds; Apps On The Recent Shelf decides whether apps join it.

The top bar and footer

The left island shows what is playing, or the last thing you opened, with the battery reading beside it. Select or UP from the top of a list brings its card out; Select twice, or a double tap, opens the player for what is playing. The time is in the centre.

The right island is your profile picture (the ECHO mark until you set one), with the notification count beside it. Its ring is the battery, filled to the charge and red at 20% or below; while it charges, echo rings spread from it. A new notification drops out of it as a card: Select once shows the newest, twice opens the panel.

The footer leads with the screen's filter or sort, one LT/RT mark and its word (tap it to step on). Then Back, the A action in the centre, the screen's own actions, and LB and RB side by side. Quick settings ▸ Button hints ▸ Minimal leaves only the filter and the A action.

The crossbar

Categories run across; everything inside a category runs down. Media columns list their apps first (Spotify under Music, Stremio under Video), then their library rows, ending with the column's own settings row (Music Settings, Video Settings). With the wave off, the focused art's colour still washes the crossbar. Inside a category the list uses the full height of the screen.

The default order is Last Played, Shelves, Game, Music, Video, Photo, Library, Network, Settings. Look ▸ Crossbar ▸ Categories creates your own (gaming for games, non-gaming for apps) and renames, hides or deletes them; built-in ones can be hidden but not deleted. Options ▸ Move Column on any row lifts its column, and Options ▸ Move lifts a system, an app or a folder row: the d-pad carries it, A drops it, B puts it back. Panel ▸ Libraries turns whole columns on and off.

Games and consoles

The Game column holds All Games, Missing (only when some files cannot be found), one card per console (or one folder per genre, with Group by Genre), its settings row and Search. LT/RT sort a list by Title, Recently Played or Date Added.

  • Add a console by hand: Emulators ▸ Library Manager ▸ Add Console, choose the platform and emulator, scan.
  • Manage a card from its ≡ menu or Library Manager: rename, change emulator, hide, scan, update metadata, scrape missing art, or remove. ROM files are never deleted.
  • Rescanning: rescan a card, use Library Manager's Scan All Consoles, or turn on System ▸ Performance ▸ Rescan On Return. A folder that cannot be read is skipped, so an unmounted SD card never empties a library.
  • Android games: Find Games on the Android system, or ≡ ▸ Mark as Game on an app. PC games: the PC system's Import PC Games.
  • Shelves: set Playing, Completed, Backlog or Favorite from a game's ≡ ▸ Shelves.
  • Genres: every game has one, from the scrapers or set with ≡ ▸ Metadata ▸ Edit Genre. ≡ ▸ Show Only <genre> filters the game lists and the drawer's Games, and the footer names it; Show All Genres clears it. Group by Genre on All Games' options turns the system folders into genre folders.

Game Info

X on a game or app opens Game Info: play time, platform and last played, then its views, which LT/RT walk: Achievements (first, when the game has them), Screenshots, Info, Video and Manual. Each shows only when there is something to show.

On Achievements the d-pad hovers a badge, X filters All / Unlocked / Locked, and A on a badge opens the full wall. A on the video plays it, on the manual opens it.

Installed emulators are detected from a built-in catalog, plus one profile per installed RetroArch core. A game launches with its own override (≡ ▸ Settings ▸ Change Emulator), then its card's emulator, then the platform default, then the recommended one. If a launch fails you get a sheet to retry, change emulator, or copy a diagnostic.

Artwork and the Artwork Studio

Art and metadata are fetched only when you ask. Sources are set up in Accounts ▸ Artwork: ScreenScraper (works without setup; an account is optional), SteamGridDB (free API key), IGDB (client ID and secret), TMDB (video posters, key) and the Steam store (no key).

The Artwork Studio (≡ ▸ Metadata ▸ Artwork) has seven slots: Tile, Tile Video, Background, Screenshot, Manual, Preview Video and Logo. It always opens on the Tile (a game's cover). Each provider is checked for every slot in the background, and a slot it has nothing for is hidden, so a game with no manual or video never shows them. Local File keeps all seven, since a file can fill any slot.

  • LT/RT step slots, LB/RB page results, X searches by another title, A picks, Start applies.
  • ≡ on a slot crops or repositions it, restores the previous image, or clears it. Crops keep the original, so you can re-crop without loss.
  • Emulators ▸ Artwork scrapes everything or only what is missing, sets video snap placement, toggles Animated Icons, and clears the cache.
  • Video snaps play muted in the tile or background when you rest on a game, but not under battery saver, below 20% when not charging, or when the device is hot.

Music, video, photos and books

Each media column scans one or more folders. Add, rescan, relink or remove them from the column's settings row (Music Settings and so on), which also picks the default player, viewer or reader app.

  • Music: Songs, Artists, Albums, Genres and Playlists open in the column like All Games. Genres come from the files; Edit Genre changes a track, a book or a whole album, and rescans keep it. Music keeps playing in the background, with its controls on the island and in the notification.
  • Video: libraries with thumbnails, Recently Watched, and the built-in player (LEFT/RIGHT seek, Options for speed and tracks) or an external app. A plays a video at once (its page is ≡ ▸ Details), Resume picks up where you stopped, and ≡ ▸ Set as Wallpaper makes it the moving wallpaper.
  • Photo: albums, the viewer (zoom, pan, rotate, slideshow), and Set as Wallpaper with EXIF stripped, framed first with the d-pad or a drag and zoomed with LT/RT or a pinch. Location data is never read.
  • Books: EPUB, PDF and CBZ by series, in the built-in reader (contents, bookmarks, your place kept; EPUB adds two-page layout, text size, typeface and page colour) or a reader app.

Search and the App Drawer

  • Search (RB, any screen) finds games, apps, music, video, photos and books together. The likeliest match stands in the middle; LT/RT filter by kind. Opening a result goes to its column and opens it.
  • The Search row at the end of Game, Music, Video, Photo and Library searches only that library.
  • Quick Search in Network searches the web: type, then A or Enter. An address opens in your browser.
  • The App Drawer (LB) shows every app as a VHS case, with Recently Used, Apps, Emulators and Games sections, and Music (albums), Videos and Books when those libraries have something, that LT/RT step through. X groups Games by system or genre, Music by artist, album or genre, and Books by author, title or genre. A game's details show its achievements and last earned badges.

The top panel

Start (twice when a notification is waiting), or two taps on the right island, opens the panel. Its tabs run along the top, and LT/RT step through them. Notifications pins what is playing at the top, or the video or book you just had open, with its art, progress and buttons.

Profile and Overview

Your name and picture (≡ edits them), games, hours and achievements, what you played last with its achievement progress, a showcase of recent badges, Discord friends, and your Steam, RetroAchievements and Discord accounts. Recently played and achievements follow your play history. The row of numbers, or its Library overview button, opens Overview: your library at a glance, with ECHO's version, the artwork and cache, and every column's counts.

System, Library and Accounts

  • Library ▸ Media Libraries: your music, video, photo and book folders. Hidden Items: anything hidden everywhere or from one place, to bring back.
  • Accounts: Permissions, RetroAchievements and Steam, the artwork services' keys, and Discord (sign-in, friends, rich presence).
  • System ▸ Performance: Thermal Throttle Awareness lowers background quality when hot, Battery Saver Mode freezes the background under battery saver, Rescan On Return looks for new and missing games when you come back (at most every five minutes).
  • System ▸ Logs: ≡ on a log ▸ Share for a bug report. Logs are redacted.

The ECHO folder

ECHO keeps its own folder on your storage, named ECHO, that you can open and edit with any file manager.

ECHO/
├ Artwork/        art for each game, one folder per console (ES-DE layout)
├ Import/         other launchers' media to bring in
├ Look/           sounds, boot audio, fonts, wallpaper and icons as files
└ settings.json   colours, wave, layout, controls and default players

ECHO keeps it current as you change things. To use your own changes, edit the files, then choose Reload ECHO Folder in the artwork folder settings: ECHO applies settings.json, any sound or icon named after its slot (sound_back.mp3, boot_audio.mp3…), a .ttf or .otf in Look/Fonts, and the newest picture or video in Look/Wallpapers. A file you edit is never written over. No passwords, keys, account details or folder paths are kept in it.

Custom icons: PNG, JPG, WebP, BMP, HEIC or animated GIF, up to 8 MB (GIFs up to 512 px, 120 frames, 10 s). Motion wallpapers: MP4, WebM, animated GIF or WebP, up to 1080p, 60 MB and 60 s.

04More

Two screens

On a handheld with a second screen, such as the AYN Thor, the XMB stays on the top screen and the bottom screen is a companion. Devices with one screen are unchanged.

  • Info follows the XMB's cursor: the focused game's details, play time, achievements and screenshots. While a game you launched is running, it shows that game and a Resume button.
  • Recent is Last Played, with its filters; with a second screen it leaves the XMB and lives here. It follows the crossbar's column (Music shows recent music), and RIGHT closes its list to show the selected item in full.
  • A session clock counts while a game you launched runs, and while music plays the companion is its remote (A play/pause, up and down skip; B goes to Recent, Y has Stop & Close).
  • The App Drawer, Search and Settings open on the bottom screen. The controller still drives them. The other screen shows the drawer's focused game as Recent does, and Search's results while you type below. A menu opens on the screen that asked for it, and the theme store shows the theme in focus on the other screen.
  • Tap a screen to give it the controller; on the companion, B hands it back. Swap (or a click of one stick, L3 or R3) puts the XMB on the bottom. Quick settings ▸ Screens switches between Dual and Single.
  • Games open on the main screen; DS and 3DS emulators keep the bottom screen while a game runs. Inlay is a gamepad keyboard that works well here.

Backup and restore

System ▸ Backup & Restore writes your library and settings to a .pfpbackup file in a folder you choose. Android's cloud backup is off, so this is how you move to a new device. Android does not carry folder access across, so after a restore relink each folder from its column's settings row, ≡ ▸ Relink Folder.

Privacy

  • No account, no analytics, no telemetry. The network is used only for artwork and metadata, over HTTPS, when you ask.
  • Your library, settings and artwork stay on the device. API keys are encrypted with a hardware-backed Android Keystore key where the device has one.
  • Logs are redacted when written. Shortcuts other apps try to add must be confirmed by you.
