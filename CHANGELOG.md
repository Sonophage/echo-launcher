# Changelog

Release notes are on the GitHub releases page. This file holds what is on `main` and not yet
released; it becomes the next release's notes.

## Unreleased (since 2.13.5)

### Main Screen and Companion Screen

- On a handheld with two displays, the Main Screen works exactly as ECHO does on one screen. Recent, the App Drawer, Search, Settings, the music player and every menu open there.
- The Companion Screen shows the Details of what the Main Screen has focused, and keeps the last thing it showed. It takes touch only, so a tap on it never moves the controller. It has Swap, and Resume while a game runs.
- Search's keyboard is on the Companion Screen. The d-pad and A type, the first B hides the keyboard and the second B closes Search.
- In Settings, the Companion Screen shows the focused setting's description and previews themes and colour schemes.
- L3 or R3 swaps the screens. On a device with one display, Swap shows the Companion Screen in place of the Main Screen, and B, L3 or R3 goes back.
- Each game and app opens on the display ECHO last launched it on. Launch on Other Screen, in the game, app and App Drawer menus, moves it. DS and 3DS emulators always open on the Main Screen's display.
- ECHO's Companion Screen is the second display's home screen.

### Context menus

- Every menu lists its rows in the same order: the item's main actions and Details first, then one divider, then the Organize, Edit, Settings, Edit Layout and Remove submenus. A submenu with one row shows that row in its place.
- The layout rows (Move, Change Icon, Change Art, Move Column, Rename Column, Change Column Icon) are in Edit Layout. Hide, Remove, Delete, Uninstall and Clear Recent are in Remove, and still ask before they act.
- Each action has one name everywhere: Details, Open Folder, Delete (erases the file), Remove from Library (the file stays), Pin to Top, Pin to Recent and Stop. A game has one Manual row. Open Folder opens the folder.
- Every row you can turn on has its pair in the same menu, such as Add to Favorites and Remove from Favorites. Favorites is one set for games, apps, videos and photos, and Shelves lists play states only.
- Every menu, rail and Quick Settings tile is in Title Case, such as Game Backgrounds and Button Hints. Game Info's view of an item's information is now called Details.

### Touch

- A press shows your theme's focus style (Classic, Halo, Bracket or Lift), the same mark the controller shows. Android's grey ripple is gone.
- While your finger is on the Side Rail, the letter or group under it bulges out to the left, clear of your thumb, with its neighbours tapering. The chosen one wears the focus style. The rail settles back at your theme's motion speed, or at once with motion reduced.
